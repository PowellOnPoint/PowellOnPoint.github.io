1 NaiveVWAP Backtest Report

This notebook analyzes the trades exported from the NaiveVWAP algorithm backtest in naiveVWAP.csv. The CSV contains per-trade details including Entry/Exit times, prices, P&L, fees, MAE/MFE, per-trade Drawdown, win/loss flag, etc. We compute equity curve, key performance metrics, and visualizations for a complete report.

View the strategy and backtest results on QuantConnect: VWAP-Trend-Rotation-Equity-Defensive-Regimes

Note: Starting capital ~$100,000

# Section 3: Calculate PNL per Trade
# Use provided P&L column and subtract Fees for net PNL
df['Net_PnL'] = df['P&L'] - df['Fees']
print('Net PnL stats:')

# Section 4: Compute Cumulative PNL
df['Cumulative_PnL'] = df['Net_PnL'].cumsum()
starting_capital = 100000
df['Equity'] = starting_capital + df['Cumulative_PnL']

# Compute drawdown from equity peak
peak = df['Equity'].cummax()
df['Drawdown'] = (df['Equity'] - peak) / peak * 100

print('Final Equity:', df['Equity'].iloc[-1])
print('Max Drawdown (%):', df['Drawdown'].min())

# Section 5: Calculate Performance Metrics
trades = len(df)
win_rate = (df['IsWin'].mean() * 100) if 'IsWin' in df.columns else 0
gross_profit = df[df['Net_PnL'] > 0]['Net_PnL'].sum()
gross_loss = abs(df[df['Net_PnL'] < 0]['Net_PnL'].sum())
profit_factor = gross_profit / gross_loss if gross_loss != 0 else float('inf')
max_dd = df['Drawdown'].min()
total_return = (df['Equity'].iloc[-1] - starting_capital) / starting_capital * 100

metrics = {
    'Total Trades': trades,
    'Win Rate (%)': round(win_rate, 2),
    'Total Net PnL': round(df['Net_PnL'].sum(), 2),
    'Total Return (%)': round(total_return, 2),
    'Profit Factor': round(profit_factor, 2),
    'Max Drawdown (%)': round(max_dd, 2),
    'Avg Trade PnL': round(df['Net_PnL'].mean(), 2)
}
print('Key Metrics:')
for k, v in metrics.items():
    print(f'{k}: {v}')

## Backtest Conclusions
The NaiveVWAP strategy generated strong positive returns (~1.47M net PnL) over the period with a 37% win rate, typical of trend-following systems that capture large winners while managing risk via the safe asset and vol targeting. Max drawdown was significant during volatile periods (e.g. large losses on TSLA/NVDA). Profit factor >1 indicates positive expectancy. Recommend further optimization of VWAP weights, crossover bonus, and universe.
